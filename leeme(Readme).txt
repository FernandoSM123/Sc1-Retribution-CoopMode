1.¿Como instalar dicho mod?

Solo extrae el archivo en la carpeta "maps" del directorio donde se encuentra instalado Starcraft

Dirección por defecto: C:\Archivos del programa\Starcraft\Maps

2.¿Que cambios incluye esta nueva version?

Cambios en varios de los mapas, en aspectos como: dificultad, objectivos de las mision, estetica del mapa, variacion en las dimensiones del mapa, etc

*************
***ENGLISH***
*************

1.How to install said mod?

Just extract the file in the "maps" folder of the directory where Starcraft is installed

Default address: C: \ Program Files \ Starcraft \ Maps

2.What changes does this new version include?

Changes in several of the maps, in aspects such as: difficulty, mission objectives, map aesthetics, variation in map dimensions, etc.
